# NEXUS v0.9 Platform Isolation Implementation Plan

**Status:** a draft for review. **Not approved, not started.** No task below has been executed. `src/` is unchanged.

**Goal:** establish I44–I49 and C29–C31 from the [v0.9 outline](../specs/2026-09-28-nexus-v0.9-outline.md):
- a platform's or an application layer's FiberRef writes never reach the fiber that starts or terminates the application, and never reach another application;
- everything else stays unchanged: the D39 precedence inside the application, finalizer semantics, lifecycle order, interruption and failure paths, the public API.

Then prove it, together with a capability requirement, in a real Chromium composition in PORT's private `integration/` workspace.

**Spec:** the outline. **The outline wins wherever the two disagree.** Evidence: the [integration audit](../../architecture/2026-09-28-valance-integration-audit.md) (IA), and the outline's §2 (E1–E3).

**Baselines:**
- **NEXUS:** `v0.8.1` (`2c5933c`), plus the audit commit `0ecfe60` and this plan's commit, on `claude/valance-integration-audit-4adgr2`. That is **391 tests in 27 files**.
- **PORT:** `v0.2.0` (`725b728`), plus the override cleanup `e9074c7`. That is port-web 242 tests and integration 15 tests. One `effect` (3.22.2), one `@valancex/mesh-runtime` (0.6.0), `@valancex/nexus` 0.8.1 and `@valancex/mesh-compiler` 0.6.0, verified with `pnpm why -r`.

**Tech stack:** TypeScript 5.6 (strict), Effect 3.22 (`^3.10.0`), Vitest 2 (NEXUS) and 3.2 (PORT), pnpm 10, and Chromium from `/opt/pw-browsers` (revision 1194).

### Task A3. The isolation helper and its two call sites

**PROPOSED CHANGE.**
- `src/runtime/internal.ts`:
  - import `Fiber` from `effect`;
  - add a module-private export `isolated`: run an effect in a supervised child fiber with `Effect.fork`, observe it with `Fiber.await` (never `Fiber.join`), forward interruption with `Effect.onInterrupt(() => Fiber.interrupt(fiber))`, and use `Effect.uninterruptibleMask` so the fork and the interrupt handler can't be separated. It is the outline's §5 code;
  - in `terminateLifecycle`, change `Scope.close(lifecycle.scope, Exit.void)` to `isolated(Scope.close(lifecycle.scope, Exit.void))` (C30). The steps before and after it are unchanged.

The bus, the lifecycle, the `addFinalizer(terminate)` registration on the caller's scope, and the `register` call stay where they are.
- **Comments.** A short comment at each call site stating the invariant (I44) and why `await`, not `join`, citing the outline §3. `isolated` isn't re-exported (the header says "nothing here is public").

### Task A5. Documentation

**PROPOSED CHANGE.** Each document states only what A3 established.

**`docs/primitives/application.md`, the "Effect's default services" bullet.** Add *caller isolation*:
- The platform's and the `runtime` layer's FiberRef settings (default services, log levels, and any `Layer.locallyScoped`) apply only inside the application.
