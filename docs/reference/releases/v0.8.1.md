# NEXUS v0.8.1 release notes

*Released 2026-09-28.*

v0.8.1 is a patch release. It moves NEXUS to MESH v0.6's runtime, so an application on MESH v0.6 has one MESH runtime, and a MESH host's render trees are MESH v0.6's. It changes no NEXUS API or behavior.

## Changes

- **`@valancex/mesh-runtime` `^0.6.0`** (was `^0.5.0`). Under 0.x semver, `^0.5.0` excludes 0.6. So an application using MESH v0.6 got a second, v0.5 runtime inside NEXUS's `Mesh.host`, whose render trees lack MESH v0.6's `propText` (the MESH text of each number, boolean and `null` prop). The host now renders with 0.6, and passes its render trees through unchanged.
  - The adapter calls only `render` and `dispatch`, and passes the `Render` through; neither changed in MESH v0.6.
  - The whole suite passes unchanged, and a new test pins that a host's render carries `propText`, and a later render its new text.
  - MESH's slice fixture is identical at MESH v0.6.0.
- **Development dependencies:** `@valancex/mesh-compiler` `^0.6.0` and `@types/node` 26.6.3. The toolchain's major versions (TypeScript 5, Vitest 2) are unchanged.
- **Release workflow, as MESH's.** Releasing is now:
  1. the release commit is tagged;
  2. the pushed `v*` tag runs all of CI on it;
  3. the workflow packs `@valancex/nexus` and checks it against the tag and npm;
  4. it publishes with provenance, and creates the GitHub release from `docs/releases/vX.Y.Z.md` (a patch release's own notes, as this file) or `vX.Y.md`.

  A manual run publishes only from a tag, and is otherwise a dry run, as is a pull request changing the workflow or `package.json`. Before, a tag push never published; only a published GitHub release did. CI runs on branch pushes only, and can be run by hand.

## Compatibility

- **No API change.** A MESH host's `Render` is `@valancex/mesh-runtime`'s, so its tree type now has MESH v0.6's optional `propText` member. Code that reads trees is unaffected, and renderers may use it.
- **MESH:** v0.6. Programs compiled by MESH v0.5 run unchanged: `template-v1`, the manifest format and model fingerprints didn't change in v0.6.
- **PORT:** PORT v0.2 has overridden NEXUS's MESH runtime range to `^0.6.0` in its test workspace. With this release that override can be removed.
