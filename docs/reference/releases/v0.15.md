# NEXUS v0.15 release notes

## v0.15.0

*Prepared 2026-10-24 (nothing tagged or published: v0.14.0 is the latest release).*

v0.15.0 is a minor release with one change: **the `@valancex/mesh-runtime` peer range is `^0.14.0 || ^0.15.0 || ^0.16.0`**. MESH 0.16 is published and v0.14.0's range stopped at 0.15, so the newest published set did not install together (the budgets' installability check, Bet 3: `npm` refused `@valancex/mesh-runtime@0.16.0` beside `@valancex/nexus@0.14.0`). Nothing in the adapter changes: MESH 0.16 adds no runtime or compiler behavior (its release is the session-log vectors of `@valancex/mesh-conformance`).

## Compatibility

- **API and behavior:** unchanged. **Install:** wider (an application on MESH 0.14, 0.15 or 0.16).
- **Tier:** not a public-API change; no audit of the north-star scorecard is touched.

## Release order

NEXUS 0.15.0, PORT 0.13.0, then the VALANCE packages (whose ranges admit MESH 0.16).

## Verification

`pnpm typecheck`, `pnpm test` (33 files, 517 tests, against MESH 0.16.0 as the development dependency) and `pnpm build`; installs under pnpm 10 and 11 with `--frozen-lockfile` (pnpm 11 needs `pnpm-workspace.yaml`, which exempts the two MESH 0.16.0 packages from the release age until a day has passed); `npm publish --dry-run` of the packed tarball.
