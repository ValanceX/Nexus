# NEXUS v0.12.2 release notes

*Prepared 2026-10-10 (nothing tagged or published).*

v0.12.2 is a patch release. It changes no API and no behavior of the runtime.

## Changes

- **`"sideEffects": false`.** `@valancex/mesh-runtime`, `@valancex/mesh-compiler` and `@valancex/port-web` already say that importing them does nothing; NEXUS did not, so a bundler had to keep, and evaluate, every NEXUS module that anything imported, even when the importing code used none of it. That put NEXUS into the bundle of a page that only needed a function from a package that happens to import it (VALANCE's entries are the case that found it). Nothing in `src` changes a global or the environment on import (`Symbol.for` for the refusal marker is a registry lookup), and `tests/package-json.test.ts` now checks both the declaration and that claim.
