# NEXUS v0.17 release notes

## v0.17.0

*Prepared 2026-10-25 (nothing tagged or published: v0.16.0 is the latest release).*

v0.17.0 is a minor release that shortens the first app (Tier 1; north-star audits T1.1 and T1.2). Both changes are additive.

- **`Runtime.make()` needs no layer.** The layer defaults to `Layer.empty`, so an application with no services yet writes `Runtime.make()`. (T1.1)
- **`Application.define({ name })` needs no `runtime`.** The input may omit it. The stored `ApplicationDefinition` still has `runtime` (filled with `Layer.empty`), so code that reads `app.definition.runtime` is unchanged. (T1.2)
- **`examples/hello`:** the smallest runnable app, with no Service, Layer or Resource. The README's first app drops its `Layer.empty` argument.
- **Docs:** the shutdown statements in `ARCHITECTURE.md`, `primitives/capability.md` and `primitives/runtime.md` that said termination does not wait for effects started with `run` or `runFork` are corrected: it waits up to the grace, then interrupts them (as since v0.12).

## Compatibility

- **API and behavior:** every existing call is unchanged; only omitted arguments are newly accepted.
