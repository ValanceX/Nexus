# NEXUS v0.12.1 release notes

*Prepared 2026-10-10.*

v0.12.1 is a patch release. It changes no API and no behavior of the runtime.

## Changes

- **`@valancex/nexus/package.json` is exported.** Every other package in the set (`mesh-runtime`, `mesh-compiler`, `port-web`, `valance`) lets a tool read its manifest through `require.resolve("<name>/package.json")`; NEXUS's `exports` map did not, so a version or peer-range check failed on it with `ERR_PACKAGE_PATH_NOT_EXPORTED`. Found by validating the released set against the API design principles. A test pins it.
