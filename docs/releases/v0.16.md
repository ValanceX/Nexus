# NEXUS v0.16 release notes

## v0.16.0

*Prepared 2026-10-24 (nothing tagged or published: v0.15.0 is the latest release).*

v0.16.0 is a minor release with one change: **the `@valancex/mesh-runtime` peer range is `^0.14.0 || ^0.15.0 || ^0.16.0 || ^0.17.0`**. MESH 0.17 adds checking a source while it arrives (a stream session in `@valancex/mesh-compiler`) and the `effect` and `title` of a command in the manifest; v0.15.0's range stops at 0.16, so the newest set would not install together. Nothing in the adapter changes: the runtime's render, update and dispatch are those of 0.16.

## Compatibility

- **API and behavior:** unchanged. **Install:** wider (an application on MESH 0.14 to 0.17).
- **Tier:** not a public-API change; no audit of the north-star scorecard is touched.

## Release order

MESH 0.17.0, NEXUS 0.16.0, PORT 0.14.0, then the VALANCE packages.

## Verification

`pnpm typecheck`, `pnpm test` and `pnpm build` against MESH 0.16.0 (the development dependency) and again against the local pack of MESH 0.17.0 (a temporary override, not committed); installs under pnpm 10 and 11 with `--frozen-lockfile`; `npm publish --dry-run` of the packed tarball.
